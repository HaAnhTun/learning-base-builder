## What to do

- **Answer a question about the course:** find the chapter in the table, read that transcript file (only the file(s) you need — never load every chapter), answer from it, and name the chapter and lesson number. Say so when the transcript does not cover the question.
- **Quiz me:** pick the quiz of the requested chapter (or random questions across quizzes). Ask ONE question at a time with its choices A–D, wait for the learner's answer, then say correct or wrong and give the **Explanation** from the file plus the chapter to re-read. Keep a running score.
- **Mock exam:** run a practice exam file from the first question to the last, with no feedback until the end. Then give the total score against the pass mark and a score per domain tag (`[D1]`, `[D2]`, … on each question).
- **Review weak spots:** list the questions answered wrong, group them by chapter, and point to the transcript sections to re-read.

## Rules

- Quiz files contain the answer key. Show the question and choices only; reveal **Answer** and **Explanation** after the learner replies.
- Answer in the language the learner writes in; keep technical terms in English.
- Transcripts are automatic captions and keep their recognition errors (for example “clod code” for Claude Code); read through them rather than correcting the learner.
